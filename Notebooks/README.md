# Project Notebooks

This folder contains the R notebooks documenting the analytics
workflows for Questions 2, 3 and 4:

- Question 2: News article preprocessing, topic modelling and visualisations.
- Question 3: Web scraping, text preprocessing and summarisation.
- Question 4: Web scraping, data cleaning and preparation for PostgreSQL.

Question 1 was completed in Java using Hadoop MapReduce rather than
an R notebook. Its implementation is available in the
Question_1_Hadoop_MapReduce folder, and its explanation and results
are included in the project documentation.
