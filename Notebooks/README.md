# Project Notebooks and Supporting Files

This folder contains the R notebooks and supporting files for
Questions 2, 3 and 4.

## Question 2: News topic modelling

The Question 2 R notebook documents the loading and preprocessing of
the news articles, Latent Dirichlet Allocation (LDA) topic modelling,
and the visualisation of the results.

The **sa_news** folder contains the input text files used by the
notebook. Keep it in the same folder as the notebook when running it.

## Question 3: Web text summarisation

The Question 3 R notebook documents the extraction, preprocessing
and summarisation of a book description.

The text was collected from the following Books to Scrape page:
https://books.toscrape.com/catalogue/join_902/index.html

## Question 4: Web scraping and ETL

The Question 4 R notebook documents the extraction and cleaning of
book listings from Books to Scrape:
https://books.toscrape.com/

The file **clean_books.csv** is the cleaned dataset created by the
notebook. It was imported into PostgreSQL for analysis.

The file **Question4_queries.sql** contains the two SQL investigations
performed on the imported data.

## Question 1: Hadoop MapReduce

Question 1 was implemented in Java using Hadoop MapReduce. Its code,
test documents and supporting files are in the
**Question_1_Hadoop_MapReduce** folder. The diagram and explanation
for Question 1.1 are included in the project documentation.
